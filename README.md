# Hi, Better Life

ქართული და ინგლისური მთავარი გვერდი Next.js App Router-ზე. საწყისი მისამართი იხსნება ქართულად (`/ka`). ინგლისური ვერსიის მისამართია `/en`.

## ლოკალური გაშვება

საჭიროა Node.js `^24` (`package.json`-ის `engines`). პროექტის საქაღალდეში გაუშვით:

```sh
npm ci
```

გარემოს ცვლადების სია არის `.env.example`-ში: `DATABASE_URL`, `DIRECT_URL`, `DB_ADMIN_URL`, `AUTH_DB_URL`, `APP_ORIGIN`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_STANDALONE_AUTH`. მნიშვნელობები ლოკალურად შეავსეთ; რეალური საიდუმლოები რეპოზიტორიაში არ ინახება. `APP_ORIGIN` production-ში უნდა იყოს HTTPS მისამართი (`https://`). ლოკალურად დაშვებულია `http://127.0.0.1:3000`.

Prisma კლიენტი გენერირდება `src/generated/prisma`-ში. დეველოპმენტ სერვერამდე გაუშვით გენერაცია, შემდეგ აპლიკაცია მხოლოდ ლოკალურ ინტერფეისზე:

```sh
npx prisma generate
npm run dev -- --hostname 127.0.0.1
```

გახსენით [ლოკალური მთავარი გვერდი](http://127.0.0.1:3000/ka). Windows PowerShell-ში ასევე შეგიძლიათ გამოიყენოთ `npm.cmd`. `npm run typecheck` და `npm run build` თავად იძახებენ `prisma generate`-ს.

## შემოწმება

```sh
npm run lint
npm run typecheck
npm run build
```

ინტეგრაციული ტესტი მხოლოდ ლოკალურ ბაზაზე, `127.0.0.1:55432`:

```sh
npm run test:integration
```

აწყობილი ვერსიის ლოკალურად გასაშვებად გამოიყენეთ `npm run start -- --hostname 127.0.0.1`.

## პირველი ეტაპის შიგთავსი

- გვერდები და საერთო განლაგება — `src/app/[locale]/`.
- მთავარი მენიუ, რესურსების ფილტრი და ქვედა ნავიგაცია — `src/components/`.
- ინტერფეისის ტექსტები და საჯარო კატალოგის ამ ეტაპისთვის შერჩეული ჩანაწერები — `messages/ka.json` და `messages/en.json`. მონაცემები სტატიკურია. რეგისტრაცია და ნავიგაცია ამ აპის მარშრუტებზეა. კონფიდენციალურობის, პირობების და თანხის დაბრუნების ცალკე გვერდები ჯერ არ არსებობს.
- ლოგო, შრიფტები, პორტრეტი და საჯარო გარეკანები — `public/brand/`. მათი წყაროები, ზომები და ბრენდის ფერები აღწერილია [ვიზუალურ ინვენტარში](docs/visual-inventory.md).
